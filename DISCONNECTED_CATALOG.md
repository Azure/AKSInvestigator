# AKS Investigator on Azure Local Disconnected Operations

This catalog lists AKS Investigator extension expansion packs (PXPs) for
Azure Local disconnected operations. Install an expansion pack in your
disconnected operations environment before creating the
`microsoft.aks.investigator` Kubernetes extension.
